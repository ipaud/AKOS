# Engineering Rules — HTML Pack

- HR1. No `onClick`-only `div`/`span` for primary interactive elements; use `button`/`a`.
- HR2. Every `<img>` has an `alt` attribute; decorative images use `alt=""`.
- HR3. Every `<input>`/`<select>`/`<textarea>` has an associated `<label>`.
- HR4. Heading levels are sequential; exactly one `h1` per page.
- HR5. `<html lang="...">` is set to the actual content language.
- HR6. Landmark elements used for page structure; no more than one `main` per page.
- HR7. Tables used only for tabular data, with `<th scope>` for headers; never for layout.
- HR8. Input `type` matches the data being collected (`email`, `tel`, `url`, `number`, `date`).
