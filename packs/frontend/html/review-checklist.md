# Review Checklist — HTML Pack

## High
- [ ] Interactive elements are native or fully ARIA-patterned. (HR1)
- [ ] All inputs have bound labels. (HR3)
- [ ] Heading hierarchy sequential, one h1. (HR4)

## Medium
- [ ] Images have appropriate alt. (HR2)
- [ ] Landmarks structure the page. (HR6)
- [ ] Correct input types used. (HR8)

## Low
- [ ] lang attribute set. (HR5)
- [ ] Tables used only for tabular data. (HR7)
