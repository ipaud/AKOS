# Anti-Patterns — HTML Pack

- **Div soup** — click handlers on non-interactive elements. See [WCAG anti-patterns](../../ux/wcag/anti-patterns.md).
- **Heading-as-styling** — using `h3` because "it looks the right size," ignoring document structure.
- **Placeholder-as-label** — no bound `<label>`, placeholder text only.
- **Layout tables** — `<table>` used for visual grid layout instead of CSS Grid/Flexbox.
- **Generic link text** — `<a>` wrapping "click here" instead of a descriptive phrase.
