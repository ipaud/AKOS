# Glossary — Design Systems Pack

- **Token pyramid** — reference → system → component token layering.
- **Design token** — a named, reusable design value (color, spacing, type).
- **Component API** — the props/slots a component exposes to consumers.
- **Deprecation path** — a transition window where old and new API coexist before removal.
- **Governance** — the review process controlling changes to shared system assets.
