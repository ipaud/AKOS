# Review Checklist — Design Systems Pack

## High
- [ ] Feature code uses tokens, not raw values. (DG1)
- [ ] Base interactive components have full state/a11y coverage centrally. (DG3)

## Medium
- [ ] Published components documented (usage, props, a11y). (DG2)
- [ ] Breaking changes have a deprecation path. (DG4)

## Low
- [ ] Shared additions reviewed by a named owner. (DG5)
