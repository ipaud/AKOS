# Glossary — CSS Pack

- **Custom property (CSS variable)** — a reusable, cascadable, themeable value defined with `--name` and consumed via `var()`.
- **Container query** — a query responding to a containing element's size rather than the viewport.
- **Logical property** — a direction-agnostic property (`margin-inline-start`) adapting to writing mode/direction.
- **Specificity** — the CSS selector-matching priority system.
