# Scoring Rubric — CSS Pack

| Finding | Deduction |
|---------|-----------|
| Layout-triggering animation on key flows | −10 (HIGH) |
| No token system, hardcoded values throughout | −10 (HIGH) |
| Desktop-first breakpoints causing mobile overrides | −6 (MEDIUM) |
| `!important` cascades | −4 (MEDIUM) |
| Wrong layout tool (fighting Flexbox/Grid) | −2 (LOW) |

Anchors: 90 tokenized, mobile-first, compositor-safe · 75 solid with gaps · 60 hardcoded values common · <50 unmaintainable specificity wars.
