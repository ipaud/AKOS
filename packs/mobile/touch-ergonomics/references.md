# References — Touch Ergonomics Pack

Attribution only. Nothing in this pack is copied from these sources; the pack is an original operational distillation reorganized into the AKOS 17-file contract. Standards requirements are restated in operational form and cited by criterion number so the normative text is one click away — read the originals before relying on any restatement here for a conformance claim.

- **Web Content Accessibility Guidelines (WCAG) 2.2** — W3C. https://www.w3.org/TR/WCAG22/
  - **SC 2.5.8 Target Size (Minimum), AA** — https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
  - **SC 2.5.5 Target Size (Enhanced), AAA** — https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html
  - **SC 2.5.1 Pointer Gestures, A** — https://www.w3.org/WAI/WCAG22/Understanding/pointer-gestures.html
  - **SC 2.5.2 Pointer Cancellation, A** — https://www.w3.org/WAI/WCAG22/Understanding/pointer-cancellation.html
  - **SC 2.5.4 Motion Actuation, A** — https://www.w3.org/WAI/WCAG22/Understanding/motion-actuation.html
  - **SC 1.4.4 Resize Text, AA** — https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html
- **HTML Living Standard — the `input` element** — WHATWG. https://html.spec.whatwg.org/multipage/input.html
- **HTML Living Standard — autofill** — WHATWG. https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#autofill
