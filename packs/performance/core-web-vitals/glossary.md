# Glossary — Core Web Vitals Pack

- **LCP (Largest Contentful Paint)** — render time of the largest visible content element; measures perceived load speed.
- **INP (Interaction to Next Paint)** — latency of user interactions across the page's lifetime, at a high percentile; measures responsiveness.
- **CLS (Cumulative Layout Shift)** — sum of unexpected layout shift impact; measures visual stability.
- **TTFB (Time to First Byte)** — time from request to first byte of server response.
- **Field data / RUM (Real User Monitoring)** — performance data collected from actual user visits, vs. lab/synthetic tests.
- **CrUX (Chrome User Experience Report)** — Google's public field-data dataset.
- **Long task** — a main-thread task exceeding 50ms without yielding.
- **Render-blocking resource** — a CSS/JS resource that must load before the browser can paint content.
- **75th percentile (p75)** — the threshold Core Web Vitals targets are measured against; 75% of visits must meet the "good" bar.
