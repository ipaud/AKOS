# Glossary — web.dev Practice Pack

- **Code splitting** — dividing a bundle into separately-loadable chunks by route/feature.
- **Lazy loading** — deferring resource load until it's needed (viewport entry, interaction, navigation).
- **Tree shaking** — build-time removal of unused exports from a bundle.
- **Content-hashed filename** — an asset filename derived from its content, enabling safe indefinite caching.
- **Skeleton screen** — a loading-state layout resembling the eventual content's structure.
- **Perceived performance** — how fast an experience *feels*, independent of measured load time.
- **Prefetching** — proactively loading a resource before it's needed, based on predicted navigation.
- **Bundle analyzer** — a tool visualizing what contributes to a JS bundle's size.
- **CDN (Content Delivery Network)** — geographically-distributed edge caching infrastructure.
