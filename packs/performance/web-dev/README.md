# Pack: web.dev Practice — Loading & Resource Optimization

**Domain:** Performance · **Authority:** Level 1 (Google/web.dev official web performance guidance) · **Version:** 1.0.0

Operationalizes the broader web.dev performance practice beyond the three Core Web Vitals metrics: bundle optimization, image/font strategy, caching, code splitting, and lazy loading — the concrete techniques that move the vitals.

Independent distillation; not affiliated with or endorsed by Google. See [references.md](references.md).

## When to load

- Bundle size and dependency review.
- Image/font/asset loading strategy.
- Caching strategy design.
- Any performance optimization pass beyond vitals measurement itself.
