# Scoring Rubric — Escaping the Build Trap Pack

Feeds [scoring/product-score.md](../../../scoring/product-score.md), org/strategy-level assessments.

| Finding | Deduction |
|---------|-----------|
| Strategy document is a feature list with no diagnosed problem/guiding policy | −15 (HIGH) |
| Roadmap commits specific features to specific dates >1 cycle out | −10 (HIGH) |
| No initiative traces to a stated higher-level outcome | −10 (HIGH) |
| Executive reporting is output-only (no outcome/value metrics) | −10 (HIGH) |
| No evidence of declined requests / features (silent-yes org) | −6 (MEDIUM) |
| PM role mandate limited to delivery coordination | −4 (MEDIUM) |

Anchors: **90** clear intent-cascade, outcome roadmaps, outcome-driven exec reporting · **75** solid with a gap (e.g. exec dashboards still output-heavy) · **60** feature-factory tendencies at multiple layers · **<50** strategy is a backlog, org rewards shipping volume exclusively.
