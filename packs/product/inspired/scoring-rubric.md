# Scoring Rubric — Inspired Pack

Feeds [scoring/product-score.md](../../../scoring/product-score.md).

| Finding | Deduction |
|---------|-----------|
| No outcome statement — initiative is a bare feature description | −15 (HIGH) |
| Value risk never tested with real customers | −15 (HIGH) |
| No discovery at all before a multi-week build commitment | −10 (HIGH) |
| Engineers absent from discovery until spec handoff | −6 (MEDIUM) |
| Usability or feasibility risk unaddressed | −6 each (MEDIUM) |
| No post-launch outcome measurement planned | −6 (MEDIUM) |
| Prototype fidelity mismatched to the risk (over-built for the question) | −2 (LOW) |

Anchors: **90** disciplined outcome-driven discovery across all four risks · **75** solid discovery with a gap or two · **60** feature-factory tendencies, thin discovery · **<50** no discovery, no outcomes, ship-and-hope.
