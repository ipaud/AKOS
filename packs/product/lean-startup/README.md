# Pack: Lean Startup

**Domain:** Product · **Authority:** Level 3 (methodology) · **Version:** 1.0.0

Operationalizes the Build-Measure-Learn loop: treat a new product/feature as a set of unproven hypotheses, test the riskiest assumption first via an MVP, measure with validated learning (not vanity metrics), and decide to persevere or pivot based on evidence.

Independent distillation; not affiliated with or endorsed by the source author. See [references.md](references.md).

## When to load

- Starting a new product or major feature under genuine market uncertainty.
- Deciding what an MVP should actually contain (and what it shouldn't).
- Choosing metrics — distinguishing vanity metrics from actionable ones.
- Persevere-vs-pivot decisions after a launch or experiment.
