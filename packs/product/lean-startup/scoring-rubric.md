# Scoring Rubric — Lean Startup Pack

Feeds [scoring/product-score.md](../../../scoring/product-score.md).

| Finding | Deduction |
|---------|-----------|
| No leap-of-faith assumption stated for a genuinely uncertain initiative | −15 (HIGH) |
| Success metric is a vanity metric, no actionable metric defined | −10 (HIGH) |
| MVP scope not traceable to the hypothesis being tested (scope creep) | −6 (MEDIUM) |
| No baseline measured before optimization | −6 (MEDIUM) |
| No pivot-or-persevere checkpoint scheduled for multi-experiment work | −4 (MEDIUM) |
| Pivot undocumented (no stated invalidated assumption / new hypothesis) | −4 (MEDIUM) |

Anchors: **90** rigorous hypothesis-driven experimentation with actionable metrics · **75** solid practice with a gap · **60** vanity-metric driven, thin hypothesis discipline · **<50** build-first-ask-later, no measurement discipline.
