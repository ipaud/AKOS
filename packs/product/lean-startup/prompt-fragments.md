# Prompt Fragments — Lean Startup Pack

## Fragment: MVP scoping lens

```text
Apply Lean Startup discipline (AKOS L3) to this initiative:
- Name the leap-of-faith assumption (value hypothesis: will customers
  want/use/pay for this; growth hypothesis: how will it acquire
  customers) — identify which is riskiest.
- Propose the smallest MVP that generates validated learning about the
  riskiest assumption specifically — not a smaller version of the full
  product, but the minimum experiment.
- Define the success metric before build: must be actionable (cohort-
  based, causally attributable), not a vanity metric (cumulative totals).
- Establish what baseline data is needed before the experiment runs.
- Suggest a pivot-or-persevere checkpoint (trigger or date) in advance.
```

## Fragment: review lens

```text
Review this product plan against Lean Startup principles:
1. Hypothesis check — is the leap-of-faith assumption named, or is the
   plan proceeding on unstated assumptions?
2. MVP-fit check — does the proposed build size match the hypothesis
   being tested, or has scope crept beyond what's needed to learn?
3. Metric check — is the success metric actionable/cohort-based, or a
   vanity metric that would look good regardless of real impact?
4. Baseline check — is there a real baseline to compare against?
5. Checkpoint check — is a pivot-or-persevere decision point scheduled?
```

## One-liner

```text
Lean Startup: name the riskiest assumption; build the smallest thing that
tests it; measure with actionable (cohort) metrics, not vanity metrics;
establish a real baseline; schedule pivot-or-persevere checkpoints;
optimize loop speed over any single build's polish.
```
