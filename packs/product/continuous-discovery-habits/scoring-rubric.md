# Scoring Rubric — Continuous Discovery Habits Pack

Feeds [scoring/product-score.md](../../../scoring/product-score.md).

| Finding | Deduction |
|---------|-----------|
| No customer touchpoint in the last 2+ weeks | −15 (HIGH) |
| No opportunity solution tree, or single-branch/single-leaf tree (decision predetermined) | −10 (HIGH) |
| Interview questions predominantly opinion/hypothetical-based | −10 (HIGH) |
| Solution nearing build with no assumption map | −10 (HIGH) |
| No test run against the top-priority assumption before build commitment | −6 (MEDIUM) |
| Research siloed to one function, no cross-functional participation | −4 (MEDIUM) |
| Synthesis lag >2 weeks between interview and tree update | −4 (MEDIUM) |

Anchors: **90** sustained weekly cadence, rich tree, disciplined assumption testing · **75** solid cadence with an occasional gap · **60** sporadic research, thin trees · **<50** no ongoing discovery, decisions made from opinion/stakeholder request alone.
