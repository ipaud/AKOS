# Decision Framework — Supabase Pack

RLS vs edge function: the access rule is expressible as "row belongs to `auth.uid()`" or similar simple predicate → RLS policy. The rule requires cross-table joins beyond RLS's comfortable expressiveness, third-party API calls, or service_role access → edge function, with the function itself validating the caller. Public vs private storage bucket: content meant to be publicly linkable (avatars, public listing images) → public bucket with public URLs; anything user-private (documents, personal uploads) → private bucket + signed URLs or RLS-gated storage policies. Prototype exception: a genuinely local-only, never-deployed prototype may defer RLS — but the moment it's deployed anywhere reachable, RLS is mandatory (matches the [Prototype profile's floor](../../../core/reasoning-profiles.md): no security leaks even at low ceremony).
