# Decision Framework — PostgreSQL Pack

Normalize vs denormalize: default normalized (single source of truth per fact); denormalize only for a measured read-performance need, with the duplication and its sync mechanism explicitly documented. Index type: B-tree (default) for equality/range/sort; GIN for full-text search/array/JSONB containment; partial index when a query always filters on a subset condition (e.g. `WHERE deleted_at IS NULL`). Migration safety for large tables: adding a column with a default on Postgres 11+ is fast (no rewrite) for non-volatile defaults; adding NOT NULL to an existing column, or a volatile default, does require a rewrite — use the nullable-then-constrain pattern for those. UUID vs serial/bigint PKs: UUID for distributed-generation/no-coordination needs or public-facing IDs (avoids enumeration); bigint/serial for internal-only, high-volume, index-locality-sensitive tables.
