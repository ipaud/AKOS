# Glossary — NIST SSDF Pack

- **SSDF (Secure Software Development Framework)** — NIST SP 800-218, a lifecycle-organized set of secure development practices.
- **PO / PS / PW / RV** — the four practice groups: Prepare the Organization, Protect the Software, Produce Well-Secured Software, Respond to Vulnerabilities.
- **SBOM (Software Bill of Materials)** — a machine-readable inventory of all components in a software artifact.
- **Provenance** — verifiable information about how a software artifact was produced (source, build process, signer).
- **Build integrity** — assurance that a build/release artifact hasn't been tampered with between source and deployment.
- **Vulnerability disclosure policy** — a published process for external parties to responsibly report security vulnerabilities.
- **Triage (vulnerability)** — assessing a reported vulnerability's severity and impact to prioritize response.
- **Threat model** — a structured analysis of what could go wrong and who might attack a system, done before or during design.
