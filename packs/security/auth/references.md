# References — Auth Pack

Attribution only. Nothing here is copied from these documents; the pack is an original
operational distillation. The normative text is always the authority — where a rule in
this pack disagrees with the specification, the specification wins.

## Primary sources (Level 1 — standards bodies)

- **RFC 9700: Best Current Practice for OAuth 2.0 Security** — IETF. https://www.rfc-editor.org/rfc/rfc9700.html
- **RFC 6749: The OAuth 2.0 Authorization Framework** — IETF. https://www.rfc-editor.org/rfc/rfc6749.html
- **OpenID Connect Core 1.0** — OpenID Foundation. https://openid.net/specs/openid-connect-core-1_0.html
- **NIST SP 800-63B: Digital Identity Guidelines — Authentication and Authenticator Management** — NIST. https://pages.nist.gov/800-63-4/sp800-63b.html

Read RFC 9700 first if you read only one: it supersedes a decade of scattered advice and
states which parts of RFC 6749 are no longer safe to use.
