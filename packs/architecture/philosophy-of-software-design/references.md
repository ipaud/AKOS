# References — Philosophy of Software Design Pack

Attribution only. Nothing here is copied from the source; the pack is an original
operational distillation, organized by the AKOS file contract rather than by the book's
structure. Read the original — it is short, opinionated, and better argued than any
summary.

- **A Philosophy of Software Design** — John Ousterhout. Yaknyam Press. https://web.stanford.edu/~ouster/cgi-bin/book.php

## A note on the disagreement

The book argues explicitly against some widely-held positions about how small units should
be. This pack records that disagreement rather than smoothing it over — see
[decision-framework.md](decision-framework.md). Treating the book as settled consensus
would misrepresent it; so would presenting it as a refutation of the other architecture
packs, which agree with it far more than they conflict.
