# Pack: Martin Fowler — Refactoring

**Domain:** Architecture · **Authority:** Level 2 (industry authority) · **Version:** 1.0.0

Operationalizes disciplined refactoring: small, behavior-preserving transformations backed by tests, named code smells that signal when to refactor, and the practice of continuous small improvement over big rewrites.

Independent distillation; not affiliated with or endorsed by the source author. See [references.md](references.md).

## When to load

- Any non-trivial change to existing code — refactoring is a build-mode default, not a special event.
- Diagnosing "this code is hard to work with" complaints (code smells).
- Deciding rewrite vs. incremental improvement.
- Reviewing whether a PR's refactoring steps stayed behavior-preserving.
