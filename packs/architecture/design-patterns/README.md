# Pack: Design Patterns

**Domain:** Architecture · **Authority:** Level 3 (methodology/reference catalog) · **Version:** 1.0.0

Operationalizes the classic Gang-of-Four pattern vocabulary as a shared naming system for recurring solutions — with heavy emphasis on when each pattern earns its complexity and when it's cargo-culted ceremony. Patterns are named solutions to *named problems*; using one without the problem present is the pack's central anti-pattern.

Independent distillation; not affiliated with or endorsed by the source authors. See [references.md](references.md).

## When to load

- A recurring structural problem needs a name and a known solution shape.
- Reviewing whether a pattern was applied to a real problem or applied for its own sake.
- Explaining an unfamiliar codebase's structure using shared vocabulary.
