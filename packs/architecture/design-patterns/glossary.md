# Glossary — Design Patterns Pack

- **GoF (Gang of Four)** — the four authors of the original Design Patterns catalog.
- **Creational / Structural / Behavioral** — the three GoF pattern families.
- **Strategy** — interchangeable algorithm objects behind a common interface.
- **Factory Method / Abstract Factory** — centralized object creation, decoupled from concrete classes.
- **Builder** — staged/optional-parameter object construction.
- **Singleton** — a class restricted to one instance; usually replaceable with dependency injection.
- **Adapter** — translates one interface to match another expected by a client.
- **Decorator** — dynamically adds behavior to individual object instances via composition.
- **Facade** — a simplified interface over a complex subsystem.
- **Composite** — uniform treatment of individual objects and groups (tree structures).
- **Observer** — subscribers notified of state changes in a subject.
- **Command** — an action represented as an object, enabling queuing/undo/logging.
- **State** — behavior that varies by an object's internal state.
- **Template Method** — a shared algorithm skeleton with overridable steps.
- **Trigger condition** — the concrete problem a pattern exists to solve; the gate for applying it.
