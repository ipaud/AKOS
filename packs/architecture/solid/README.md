# Pack: SOLID Principles

**Domain:** Architecture · **Authority:** Level 3 (methodology) · **Version:** 1.0.0

Operationalizes the five SOLID class/module design principles — Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion — as concrete checks, with explicit guidance on when applying them adds value vs. adds ceremony.

Independent distillation; not affiliated with or endorsed by the source authors. See [references.md](references.md).

## When to load

- Reviewing class/module design for coupling and change-resistance.
- Deciding whether to split a class, extract an interface, or introduce abstraction.
- Diagnosing "this is hard to change without breaking things" complaints.
