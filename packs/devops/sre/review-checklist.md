# Review Checklist — SRE Pack

## High
- [ ] SLIs/SLOs defined for critical user journeys. (SR-E1)
- [ ] Paging alerts are symptom-based with documented rationale. (SR-E2)
- [ ] Every alert links to a runbook. (SR-E3)

## Medium
- [ ] Postmortems blameless, with tracked follow-up actions. (SR-E4)
- [ ] Error budget status reviewed on a regular cadence. (SR-E5)

## Low
- [ ] Recurring manual toil tracked and prioritized for automation. (SR-E6)
