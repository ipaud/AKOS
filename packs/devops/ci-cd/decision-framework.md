# Decision Framework — CI/CD Pack

CI rigor by profile: Prototype — lint + basic tests, manual deploy acceptable; MVP — full pipeline, automated deploy to staging, manual promote to production; Production — full pipeline, automated deploy to production from main, automated rollback; Enterprise — full pipeline + security scanning gates + staged rollout (canary/blue-green) + automated rollback with monitoring-triggered auto-rollback. Deploy frequency: continuous deployment (every merge to main auto-deploys) suits teams with strong test coverage and feature-flag discipline; continuous delivery (every merge is deployable, but deploy is a deliberate trigger) suits teams wanting a human checkpoint — both are legitimate, pick based on team readiness (test coverage, monitoring, rollback speed) not aspiration alone.
