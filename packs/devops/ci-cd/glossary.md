# Glossary — CI/CD Pack

- **Continuous Integration (CI)** — automatically verifying every merge to main via a test/build pipeline.
- **Continuous Delivery (CD)** — keeping main always deployable; deploy triggered deliberately.
- **Continuous Deployment** — every passing merge auto-deploys to production.
- **Pipeline gate** — a required-pass check before merge/deploy proceeds.
- **Feature flag** — a runtime toggle decoupling code deployment from user-facing release.
- **Canary/blue-green deployment** — staged rollout strategies limiting blast radius of a bad release.
