# Glossary — Git Pack

- **Atomic commit** — a commit containing exactly one logical, reviewable change.
- **Conventional commits** — a `type: description` commit message convention (feat/fix/refactor/etc.).
- **Trunk-based development** — a branching strategy favoring short-lived branches merged frequently to main.
- **Git Flow** — a branching strategy with develop/release/hotfix branches for scheduled release trains.
- **Force-push** — overwriting remote history; dangerous on shared branches.
- **Bisect** — git's binary-search tool for finding the commit that introduced a bug.
