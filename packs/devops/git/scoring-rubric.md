# Scoring Rubric — Git Pack

| Finding | Deduction |
|---------|-----------|
| Secrets present in commit history | −25 (CRITICAL — also security) |
| Force-push to shared/main branch | −15 (HIGH) |
| Chronically uninformative commit messages | −6 (MEDIUM) |
| Mega-commits mixing unrelated changes | −6 (MEDIUM) |
| Weeks-long unrebased feature branches causing conflict pain | −4 (MEDIUM) |
| Inconsistent merge strategy | −2 (LOW) |

Anchors: 90 clean atomic history, no secrets, disciplined branching · 75 solid with occasional messy commits · 60 frequent mega-commits/vague messages · <50 secrets in history or destructive force-pushes.
