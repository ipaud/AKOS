# Review Checklist — Git Pack

## High
- [ ] No secrets/credentials in commit history. (GT-E3)
- [ ] Commits are atomic, no unrelated changes mixed. (GT-E2)

## Medium
- [ ] Commit messages follow type: description format with why explained. (GT-E1)
- [ ] No force-push to shared/main branches. (GT-E4)

## Low
- [ ] Consistent merge strategy across the repo. (GT-E5)
- [ ] .gitignore configured appropriately from project start. (GT-E6)
