# Pack: Apple Human Interface Guidelines

**Domain:** UX/Platform · **Authority:** Level 1 *on Apple platforms* (platform owner's official guidelines) · **Version:** 1.0.0

Operationalizes Apple HIG thinking for iOS/iPadOS/macOS (and web apps aiming for native-feel on Apple devices): clarity, deference, depth; platform conventions; touch ergonomics; feedback; system integration. On Apple platforms this pack outranks generic UI advice ([Ruling R3](../../../core/conflict-resolution.md)); off them, it demotes to a well-argued Level 2 voice.

Independent distillation; not affiliated with or endorsed by Apple. Normative source: developer.apple.com/design — see [references.md](references.md).

## When to load

- Building iOS/iPadOS/macOS apps (native, React Native, Flutter, Catalyst).
- PWAs/web apps where most traffic is iOS Safari.
- Deciding navigation, gesture, and control patterns on Apple devices.
- Reviewing touch-target, typography (Dynamic Type), and safe-area handling.
