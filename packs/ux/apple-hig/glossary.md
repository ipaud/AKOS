# Glossary — Apple HIG Pack

- **Clarity / Deference / Depth** — the HIG's three design commitments.
- **Navigation stack** — hierarchical push/pop container with edge-swipe back.
- **Sheet** — card-style modal for scoped tasks; explicit resolution expected.
- **Tab bar** — persistent bottom bar switching parallel top-level sections, each with its own stack.
- **Alert** — interruption for critical decisions; the scarcest UI resource.
- **Size classes** — compact/regular width–height traits driving adaptive layout.
- **Safe area** — screen region guaranteed free of hardware/system intrusions.
- **Dynamic Type** — user-controlled semantic text sizing system.
- **SF Symbols** — Apple's variable-weight icon vocabulary aligned to text styles.
- **Semantic colors** — system-defined color roles auto-adapting to appearance/accessibility.
- **Haptics (semantic)** — system feedback vocabulary: success, warning, error, selection.
- **Reduce Motion / Reduce Transparency** — accessibility settings apps must honor.
- **Launch screen** — the static UI-skeleton first frame; not a splash ad.
- **Catalyst / native-feel** — iPad-to-Mac porting tech; Mac-ness still must be earned (menus, shortcuts, density).
