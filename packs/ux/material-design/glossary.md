# Glossary — Material Design Pack

- **M3 (Material You)** — third-generation Material: tonal palettes, dynamic color, updated components.
- **Token pyramid** — reference → system → component tokens; theming happens mid-layer.
- **Role pair** — color role + guaranteed-contrast counterpart (`primary`/`on-primary`).
- **Tonal palette** — 13-step tonal ramp generated per key color; source of scheme roles.
- **Dynamic color** — user-wallpaper-derived palettes re-keying app schemes on Android.
- **State layer** — standard-opacity overlay expressing hover/focus/pressed/selected uniformly.
- **Elevation / tonal surface** — layer level expressed by shadow and/or surface tone (dark theme favors tone).
- **Emphasis ladder** — filled → tonal → elevated → outlined → text button hierarchy.
- **FAB** — floating action button; a screen's single signature action.
- **Snackbar** — transient message with ≤1 optional action.
- **Banner** — persistent condition surface until resolved.
- **Navigation bar / rail / drawer** — width-class-dependent navigation containers.
- **Canonical layouts** — list-detail, feed, supporting pane; large-canvas patterns.
- **Anatomy sheet** — a component's full spec: parts, measurements, states, motion, semantics.
- **Density tokens** — systematic compactness controls preserving touch minimums.
