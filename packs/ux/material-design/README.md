# Pack: Material Design

**Domain:** UX/Platform · **Authority:** Level 1 *on Android / Material surfaces* (platform owner's official system) · **Version:** 1.0.0

Operationalizes Material Design (M3 era) for Android apps and Material-styled web apps: the component system, elevation/hierarchy model, motion semantics, interaction states, layout/density rules, and design tokens. On Android it outranks generic UI advice ([Ruling R3](../../../core/conflict-resolution.md)); on the web it's a strong Level 2-style voice when Material is the chosen system.

Independent distillation; not affiliated with or endorsed by Google. Normative source: m3.material.io — see [references.md](references.md).

## When to load

- Android apps (native, RN, Flutter/Material widgets).
- Web apps built on Material-derived component libraries (MUI etc.).
- Token architecture decisions (Material's token system is the reference model).
- Cross-platform grammar decisions alongside [apple-hig](../apple-hig/README.md).
