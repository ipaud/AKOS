# Review Checklist — Laws of UX Pack

## High

- [ ] Decision points on primary flows: ≤5 undifferentiated options, or grouped/defaulted/disclosed. (LX1)
- [ ] Most frequent action per screen: largest + nearest of its group; touch minimums met. (LX3, LX5)
- [ ] Destructive actions: never largest/nearest/default-focused. (LX4)
- [ ] Standard objects follow convention, or deviation is justified in writing. (LX7)
- [ ] No screen requires recall from a previous screen. (LX8)
- [ ] Flows ≥3 steps show honest progress. (LX11)
- [ ] Key journeys end on a designed completion state (result + location + next). (LX12)
- [ ] Exactly one isolated primary element per decision surface. (LX14)

## Medium

- [ ] Majority-case defaults pre-selected. (LX2)
- [ ] Dialog/wizard controls positioned consistently, near their content. (LX6)
- [ ] Identifiers chunked. (LX9)
- [ ] Inferrable inputs inferred, with override. (LX10)
- [ ] Waiting states >1s designed. (LX13)
- [ ] Distinctiveness not color-only. (LX15)
- [ ] Nav arrays: priority items first and last. (LX16)

## Low

- [ ] Accent styling ≤ ~10% of elements. (LX14)
- [ ] Sub-goals named in flows ≥6 steps. (LX11)
- [ ] Test protocols capture behavior, not only satisfaction. (LX17)

## Meta

- [ ] Every law-cited finding checked against the law's boundary conditions (no law laundering).
- [ ] Contested findings carry their evidence-upgrade path (analytics or 3-user test).
