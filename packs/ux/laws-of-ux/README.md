# Pack: Laws of UX — Cognitive Laws for Interface Decisions

**Domain:** UX · **Authority:** Level 2 (compiled psychology research; the compilation is L3, the underlying laws are peer-reviewed) · **Version:** 1.0.0

Operationalizes the named psychological laws most useful in interface work: Hick, Fitts, Jakob, Miller, Tesler, Peak-End, Serial Position, Von Restorff, Aesthetic-Usability, Goal-Gradient. Where [Krug](../steve-krug/README.md) and [NN/g](../nielsen-norman-group/README.md) give practice, this pack gives the quantified *why* — useful when a design argument needs more than taste.

Independent distillation for personal engineering use. Not affiliated with or endorsed by the source authors. See [references.md](references.md).

## When to load this pack

- Sizing/placing interactive targets and menus (Fitts, Hick).
- Deciding how many options/steps/items to expose (Hick, Miller, Tesler).
- Designing onboarding, checkout ends, progress mechanics (Peak-End, Goal-Gradient).
- Arguing against a stakeholder's "more options/more features on screen" (Hick, Tesler).
- Making something stand out or be remembered (Von Restorff, Serial Position).

## Law index

| Law | One-line operational form |
|-----|---------------------------|
| Hick's | Decision time grows with number and ambiguity of choices — cut or chunk options |
| Fitts's | Acquisition time grows with distance/size ratio — big, close targets for frequent actions |
| Jakob's | Users import expectations from everywhere else — default to convention |
| Miller's | Working memory holds ~7±2 chunks — chunk, don't count on memory |
| Tesler's | Complexity is conserved — someone pays; make it the system, not the user |
| Peak-End | Experiences are judged by peak + ending — engineer both |
| Serial Position | First and last items are remembered — position accordingly |
| Von Restorff | The different one is remembered — spend distinctiveness on one thing |
| Aesthetic-Usability | Attractive interfaces are perceived as more usable — polish buys tolerance, and masks problems in testing |
| Goal-Gradient | Motivation rises near completion — show progress, shrink perceived distance |
