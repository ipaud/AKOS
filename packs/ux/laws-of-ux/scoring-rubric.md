# Scoring Rubric — Laws of UX Pack

Feeds [scoring/ux-score.md](../../../scoring/ux-score.md) as the cognitive-cost component.

## Deductions (from 100)

| Finding | Deduction |
|---------|-----------|
| Fake/dishonest progress or dark-pattern gradient exploitation | −25 (CRITICAL — trust) |
| Destructive action largest/nearest/default-focused | −10 (HIGH) |
| Cross-screen recall required on a primary flow | −10 (HIGH) |
| Choice wall (>5 undifferentiated) at a primary decision point | −10 (HIGH) |
| Convention broken on standard objects without justification | −10 (HIGH) |
| Journey ending undesigned (no completion state) | −4 (MEDIUM) |
| Missing progress on ≥3-step flow | −4 (MEDIUM) |
| Complexity dumping (inferable field asked, format homework) | −4 each, cap −12 (MEDIUM) |
| Highlight inflation (accent >10% / multiple primaries) | −4 (MEDIUM) |
| Touch-target violations | −4 per screen, cap −12 (MEDIUM) |
| Unchunked identifiers, color-only distinctiveness, undesigned waits | −1 each, cap −6 (LOW) |

## Modifiers

- Flow cost audit performed with reductions applied: +5.
- Law-laundered finding submitted by the review itself: reviewer must fix; laundering discovered post-hoc invalidates the affected deduction.

## Anchors

- **92** — costs tallied and minimized; endings designed; one accent discipline holds.
- **80** — sound structure; a few complexity dumps and undesigned waits.
- **70** — choice walls or recall demands on primary flows; fix before scale.
- **<60** — dark-pattern gradients or systematic Fitts hazards on destructive ops; BLOCKED.
