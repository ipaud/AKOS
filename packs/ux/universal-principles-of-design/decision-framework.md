# Decision Framework — Universal Principles Pack

## Named tensions and their default resolutions

| Tension | Default | Flip when |
|---------|---------|-----------|
| Flexibility vs usability (UP16) | Usability — focused core, fewer options | Users are daily professionals whose workflows genuinely diverge |
| Signal density vs disclosure (UP11/UP8) | Disclose — core visible, rest on demand | Comparison/monitoring tasks where density *is* the signal (dashboards) |
| Forgiveness vs friction (UP13/UP12) | Forgiveness (undo/retention) with minimal friction | Truly irreversible + high-stakes → add forcing functions ([table](../don-norman/decision-framework.md)) |
| Consistency vs local optimum (UP18) | Consistency | Migration executed globally, not locally ([R9](../../../core/conflict-resolution.md)) |
| Enclosure vs whitespace (UP1/UP3) | Whitespace/proximity first | Dense data grids where boxes carry scanning structure |
| Iteration vs polish (UP21) | Iterate rough, polish what survives | Aesthetic-usability testing hazard: polish *before* user tests ([LX17 caveat](../laws-of-ux/heuristics.md)) |

## Choosing the grouping cue

Need to show relationship → weakest sufficient cue, in order: proximity → similarity → continuity/alignment → common region → explicit connection (lines/labels). Each step up adds noise; jumping straight to boxes-and-lines is the amateur tell ([border fever](../refactoring-ui/anti-patterns.md)).

## 80/20 allocation decision

Given limited build/polish budget: rank tasks by (usage × importance); spend on the top slice until marginal value drops below the next tier's top item. Explicitly *underserve* the tail — a mediocre rare-path is correct allocation, not negligence, provided it's honest (works, just unpolished) and safe.

## When universal principles disagree with a school pack

The school pack (Krug/Norman/NN-g) wins on its home turf — it's the specialized derivative. This pack wins when the school packs are silent or when connecting findings across them. Either way the tradeoff statement names both sources.
