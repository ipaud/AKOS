# Review Checklist — Universal Principles Pack

Connective-tissue review; school packs' checklists own their turf.

## High

- [ ] Grouping cues truthful: spacing ratios, style-kind mapping, enclosures all report real relationships. (UD1–UD3)
- [ ] Top-5 actions ≤2 interactions from natural context. (UD6)
- [ ] Destructive actions carry forgiveness beyond confirmation (undo/trash/drafts), incl. storage-layer support. (UD9)
- [ ] Delayed consequences surfaced (quota, sends, jobs, billing). (UD12)

## Medium

- [ ] ≤3 primary alignment edges per screen; grid discipline. (UD4)
- [ ] Layer stacking disambiguated (scrim/elevation). (UD5)
- [ ] Rare capability disclosed, not inline. (UD7)
- [ ] Sequences >5 chunked into named groups. (UD8)
- [ ] Decorative noise absent from task surfaces. (UD11)

## Low

- [ ] New options carry flexibility pricing; sub-2% toggles flagged for removal. (UD10)
- [ ] Named tensions in contested decisions resolved with recorded tradeoffs.
