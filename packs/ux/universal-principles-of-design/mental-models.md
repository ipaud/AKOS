# Mental Models — Universal Principles Pack

## Gestalt as the layout compiler

The eye runs grouping rules in fixed priority before conscious thought: enclosure > connection > proximity > similarity > continuity. Layout is programming that compiler: put the relationship in the strongest cue that's quiet enough ([separation ladder](../refactoring-ui/mental-models.md) is this model applied). Debugging a confusing layout = finding which Gestalt cue is firing falsely.

## The vital few (80/20 as an audit)

Rank features by usage; compare against the surface area, polish, and nav priority each receives. The mismatches are the roadmap: over-served rarities (candidates for disclosure/removal) and under-served workhorses (candidates for acceleration and polish). Same audit applies to settings, docs, and even error messages.

## Forgiveness economics

Every forgiving mechanism (undo, drafts, versioning, trash retention, edit windows) converts user fear into exploration. Fear is invisible in analytics but shows as: low feature adoption, support tickets asking permission ("will this delete…?"), and users maintaining external backups. Forgiveness pays in confidence — usually the cheapest UX investment with the widest effect ([undo > confirm](../don-norman/decision-framework.md) is its sharpest case).

## Performance load as the universal currency

Physical actions (clicks, typing, reaching) + cognitive operations (decisions, recall, parsing) = the price of every task. All the pack's efficiency principles — chunking, disclosure, defaults, constraint, 80/20 — are load-reduction strategies. When comparing designs, tally the load ([flow cost audit](../laws-of-ux/prompt-fragments.md) operationalizes this).

## Flexibility as a mortgage

Every option, mode, and configuration a design accommodates is borrowed usability, repaid with interest by every user forever (more decisions, more docs, more states to test). Sometimes worth it (pro tools); always worth *pricing*. The question isn't "could someone want this?" but "does accommodating it degrade the core for everyone?"
