# Prompt Fragments — Universal Principles Pack

## Fragment: build-mode constraint block

```text
Apply universal design principles (AKOS L3, connective layer):
- Gestalt truthfulness: spacing ratios encode real relationships
  (unrelated ≥1.5× related); one style per semantic kind; enclosure only
  when proximity+background insufficient; ≤3 primary alignment edges.
- 80/20: top actions ≤2 interactions deep; rare capability behind
  progressive disclosure; polish budget follows usage.
- Forgiveness: destructive actions get undo/trash/drafts (design the
  storage for it: soft deletes, history); confirmation reserved for the
  irreversible remainder.
- Load shaving: every step gives up at least one decision/input/recall to
  a default, inference, or removal.
- Flexibility pricing: no new option/setting without who-needs-it,
  %-served, and cost-to-the-rest recorded.
- Closed loops: delayed consequences (quota, sends, jobs, billing)
  surface where users will look.
```

## Fragment: connective review lens

```text
Review using the universal-principles layer:
1. Gestalt audit — find grouping cues that misreport relationships
   (spacing lies, similarity lies, false enclosures, ambiguous layers).
2. 80/20 audit — compare feature usage/importance to surface area, nav
   depth, and polish; list inversions.
3. Forgiveness audit — inventory destructive actions vs their recovery
   mechanisms; flag confirmation-only guards.
4. Flexibility audit — settings/options serving <2% or added to dodge a
   design decision.
5. Loop audit — actions with invisible delayed consequences.
When findings overlap a school pack (Krug/Norman/NN-g/RUI), cite both and
report once — this layer explains agreements, it doesn't duplicate them.
```

## One-liner

```text
Universal: truthful grouping cues (proximity>boxes); 80/20 allocation;
progressive disclosure; forgiveness over confirmation; shave load every
step; price all flexibility; close feedback loops; iterate cheap.
```
