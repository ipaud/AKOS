# Pack: Steve Krug — Web Usability

**Domain:** UX · **Authority:** Level 2 (industry authority) · **Version:** 1.0.0

Operationalizes Steve Krug's usability thinking — the "don't make me think" school: interfaces should be self-evident, users scan rather than read, and small cheap usability tests beat big expensive opinions.

Independent distillation for personal engineering use. Not affiliated with or endorsed by the source authors. See [references.md](references.md) for the originals — buy/read them; this pack is a lossy operational index, not a substitute.

## When to load this pack

- Reviewing any user-facing screen, flow, or navigation.
- Writing or cutting interface copy.
- Designing homepages, landing pages, nav systems.
- Planning usability testing on any budget.
- Whenever a design debate needs the tiebreak question: *"does this make the user think?"*

## Core claim, one line

Every moment a user spends figuring out your interface is a withdrawal from a limited reserve of goodwill — design so there's nothing to figure out.
