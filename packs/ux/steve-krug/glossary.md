# Glossary — Krug Pack

- **Cognitive friction** — effort spent interpreting the interface instead of pursuing the goal. The unit this pack minimizes.
- **Goodwill reservoir** — the finite, per-user reserve of patience; drained by friction and dishonesty, refilled by obviousness and effort-saving.
- **Happy talk** — self-congratulatory or welcoming copy carrying no user value; identifiable by working equally well on any site.
- **Mindless choice** — a decision a user can make without deliberation; the quality bar for steps in a flow.
- **Muddling through** — using an interface via a working-but-wrong mental model; the normal state of real users.
- **Mystery meat** — interactive elements whose meaning is hidden until hover/tap.
- **No-think test** — walking a flow as a first-timer and logging every hesitation; core review move.
- **Satisficing** — choosing the first plausible option rather than the best one; normal user strategy.
- **Scanning** — reading a page as a billboard: headings, links, keywords only.
- **Scent (information scent)** — how strongly a link's wording predicts what's behind it; strong scent makes depth cheap.
- **Self-evident** — understood at a glance with zero reading; the top rung of clarity.
- **Self-explanatory** — understood with minimal in-place reading; the acceptable fallback rung.
- **Squint test** — blurring the page to check that visual prominence encodes importance.
- **Think-aloud test** — a usability session where the participant narrates their reasoning while attempting goal-phrased tasks.
- **Trunk test** — checking whether a random interior page orients a teleported-in user (site, page, sections, position, home, search).
- **You-are-here indicator** — the visual + semantic marking of current location in navigation.
