# Pack: Don Norman — Design of Interaction

**Domain:** UX · **Authority:** Level 2 (industry authority) · **Version:** 1.0.0

Operationalizes Don Norman's human-centered design vocabulary: affordances, signifiers, mapping, feedback, conceptual models, constraints, the two gulfs, and the slips-vs-mistakes error taxonomy. Where the [Krug pack](../steve-krug/README.md) tells you *that* interfaces must be obvious, this pack explains *why* they aren't — and gives the mechanical levers to fix it.

Independent distillation for personal engineering use. Not affiliated with or endorsed by the source authors. See [references.md](references.md) for the originals — buy/read them; this pack is a lossy operational index, not a substitute.

## When to load this pack

- Designing novel interactions (no convention to borrow).
- Diagnosing *why* users fail at a flow (gulf analysis, error taxonomy).
- Reviewing feedback, state visibility, and control-effect mapping.
- Any physical/spatial UI: games, canvas tools, drag-and-drop, gestures.

## Core claim, one line

When people fail to use something, the fault lies in the design's communication — discoverability and understanding are properties the designer either built or didn't.
