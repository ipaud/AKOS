# Glossary — WCAG Pack

- **POUR** — the four principles: Perceivable, Operable, Understandable, Robust.
- **Success criterion (SC)** — a testable pass/fail statement in WCAG, numbered (e.g. 1.4.3); levels A/AA/AAA.
- **Conformance level** — A (minimum), AA (standard legal/industry target), AAA (enhanced, selectively adopted).
- **Accessibility tree** — the browser's parallel structure of roles/names/states consumed by assistive technology.
- **Accessible name** — the computed label AT announces for an element (from content, `label`, `aria-label`, `aria-labelledby`).
- **Role** — what kind of thing an element is to the tree (button, dialog, tab).
- **ARIA** — Accessible Rich Internet Applications; attributes that *promise* semantics/behavior to the tree. Unkept promises are defects.
- **APG** — the W3C ARIA Authoring Practices Guide; the canonical keyboard/role/state patterns for custom widgets.
- **Landmark** — page region with a navigational role (`main`, `nav`, `banner`, `contentinfo`).
- **Live region** — element whose content changes are announced by AT without focus (`aria-live` polite/assertive).
- **Focus trap** — focus that cannot leave a region; a defect page-wide, a requirement inside open modals.
- **Focus-visible** — the visible indicator of keyboard focus; removable only with an equivalent replacement.
- **Reflow** — content adapting to 320px-equivalent width without 2D scrolling (SC 1.4.10).
- **Contrast ratio** — luminance ratio between foreground/background; floors 4.5:1 text, 3:1 large text and UI components.
- **Skip link** — first focusable link jumping past repeated blocks to main content.
- **Curb-cut effect** — accessibility features benefiting far broader populations than their target.
- **AT (assistive technology)** — screen readers, magnifiers, switch devices, voice control, and kin.
- **VPAT** — Voluntary Product Accessibility Template; the standard conformance-claim document (Enterprise profile).
