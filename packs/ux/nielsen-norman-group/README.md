# Pack: Nielsen Norman Group — Usability Heuristics & Research Practice

**Domain:** UX · **Authority:** Level 2 (industry authority) · **Version:** 1.0.0

Operationalizes the Nielsen Norman Group school: the ten usability heuristics as a working evaluation system, plus the research discipline behind them (heuristic evaluation, severity ratings, discount usability). This is AKOS's backbone checklist vocabulary — most UX findings cite one of the ten heuristics as their category.

Independent distillation for personal engineering use. Not affiliated with or endorsed by the source authors. See [references.md](references.md) for the originals.

## When to load this pack

- Any structured UX review — the ten heuristics are the default finding taxonomy.
- Heuristic evaluation of a competitor or an existing product.
- Assigning severity to usability findings.
- Settling "is this actually a problem?" debates with a named, citable violation.

## The ten heuristics (index)

| # | Heuristic | Shorthand |
|---|-----------|-----------|
| H1 | Visibility of system status | "What's happening?" |
| H2 | Match between system and real world | "Speak my language" |
| H3 | User control and freedom | "Emergency exit" |
| H4 | Consistency and standards | "Don't surprise me" |
| H5 | Error prevention | "Stop me before I err" |
| H6 | Recognition rather than recall | "Show, don't quiz" |
| H7 | Flexibility and efficiency of use | "Accelerators for experts" |
| H8 | Aesthetic and minimalist design | "Every element earns its place" |
| H9 | Help users recognize, diagnose, recover from errors | "Errors that help" |
| H10 | Help and documentation | "Help as last resort, findable" |
