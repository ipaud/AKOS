# Glossary — Refactoring UI Pack

- **Type scale** — the fixed set of font sizes a product may use.
- **Spacing scale** — the fixed set of gap/padding values; steps differ ≥ ~25%.
- **Shade ramp** — 8–10 pre-designed tints/shades of one hue covering all its jobs.
- **Token** — a named design value (`text-secondary`, `elevation-2`) referenced instead of raw values.
- **Separation ladder** — whitespace → background shift → shadow → border; use the lowest rung that works.
- **Visual loudness** — an element's combined attention pull (size, weight, contrast, saturation, motion); budgeted per screen.
- **De-emphasis** — quieting neighbors to create emphasis without amplification.
- **Accent budget** — the one-per-surface allowance of accent-colored elements.
- **Label subordination** — labels styled quieter than the data they describe, or folded into it.
- **Scrim** — a translucent layer between image and text guaranteeing contrast.
- **Tabular figures** — equal-width numerals for aligned columns.
- **Personality dials** — the token-level settings (radius, hue energy, density, type voice) that encode brand character.
- **Swipe file** — a curated collection of admired interfaces, mined for systems rather than pixels.
