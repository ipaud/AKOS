# Pack: Refactoring UI — Visual Craft for Non-Designers

**Domain:** UX/Visual · **Authority:** Level 3 (book/methodology) · **Version:** 1.0.0

Operationalizes the Refactoring UI school of practical visual design: hierarchy through weight and color rather than size alone, systematic spacing scales, restrained palettes, and improving interfaces by *removing* visual noise. This is the "make it look designed" pack — it composes with [steve-krug](../steve-krug/README.md) (obviousness) and [wcag](../wcag/README.md) (floors, which win conflicts).

Independent distillation for personal engineering use. Not affiliated with or endorsed by the source authors. See [references.md](references.md).

## When to load

- Building any UI without a dedicated designer.
- Polish passes after functional completion.
- Design-system/token decisions (spacing, type, color scales).
- Reviews where the finding is "works but looks amateur".

## Core claim

Interfaces look designed when every visual property — size, weight, color, spacing, depth — is chosen from a deliberate constrained system and used to encode hierarchy, instead of being picked per-element by feel.
