# Changelog — ux-writing

## [1.0.0] — 2026-07-19

### Added

- First complete version: all 17 schema files populated with operational content.
- Principles UW1–UW16 covering label truthfulness, voice/tone as a system, terminology consistency, message anatomy, commitment-point microcopy, and text-as-data.
- Engineering rules UWE1–UWE45, grouped into truthfulness, terminology, buttons, errors and validation, forms, zero states, feedback, copy accessibility, and internationalization.
- Anti-patterns derived from a real production audit: lying labels, phantom confirmations, capability cosplay, synonym drift, tooltip-only meaning, dead-end empty states, euphemistic status, implementation vocabulary leaks, mixed label grammar, and double confirmations.
- Review checklist and scoring rubric that treat label/behaviour mismatch as a correctness defect, with a hard cap at 59 for any open truthfulness finding.
- Scope boundary recorded against `packs/content/gov-uk-content-design` (long-form content) and `packs/ux/steve-krug` (screen-level clarity).
