# Changelog — gov-uk-content-design

## [1.0.0] — 2026-07-19

### Added

- First complete version: all 17 schema files populated with original operational content.
- Principles GC1–GC16 covering user need, user vocabulary, task-based structure, plain language as cost reduction, front-loading, scanning, format-as-meaning, named actors, one-page-one-need, evidence over preference, titles, maintainability, retirement, and post-launch iteration.
- Engineering rules GCE1–GCE40 with checkable numeric targets: readability grade levels, 25-word sentence ceiling, paragraph and page-length limits, 65-character titles, three-word front-loading, format thresholds for steps/tables/branching, banned-phrase detection lists, and review-date windows.
- Anti-patterns with detection cues: org-chart content, the question nobody asked, happy talk preamble, the hidden actor, topic sprawl, jargon laundering, zombie content, duplicate answers, the attachment dump, and publish-and-forget.
- Review checklist and scoring rubric treating factual staleness and unassigned obligations as CRITICAL user-harm defects rather than style issues.
- Invented before/after examples using fictional organisations; no source material reproduced.
- Scope boundary recorded against `packs/content/ux-writing` (interface microcopy) and `packs/ux/steve-krug` (screen usability).
