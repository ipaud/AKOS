# Review Checklist — GOV.UK Content Design Pack

Binary checks, ordered by severity. Each unchecked box is a finding at the listed severity. Used by the copy lens of the AKOS review pipeline.

## Critical (blocks in every profile)

- [ ] The content is factually correct and current — no known-wrong prices, dates, thresholds, or system names. (GC14, GCE39)
- [ ] Every instruction, obligation, deadline and consequence names who must act. (GC8, GCE8)
- [ ] The page answers a stated user need whose beneficiary is the user, not the organisation. (GC1, GCE1–GCE2)
- [ ] No content on a task-critical path is past its review date without re-verification. (GCE39)
- [ ] Content required to complete a task is available as HTML, not only inside an attachment. (GCE33)

## High

- [ ] The answer is in the first sentence; there is no preamble before it. (GC5, GCE10)
- [ ] Title is front-loaded, ≤ 65 characters, states the outcome, and is honoured by the page. (GC13, GCE13)
- [ ] Readability meets target: grade level ≤ 6 general / ≤ 9 specialist with audience recorded. (GCE5)
- [ ] No sentence exceeds 25 words; mean ≤ 20. (GCE6)
- [ ] Ordered sequences of 3+ actions are numbered steps, not prose. (GC7, GCE15)
- [ ] Multi-attribute comparisons are tables, not repeated paragraphs. (GCE16)
- [ ] Branching eligibility with 3+ conditions is not nested prose conditionals. (GCE22)
- [ ] Page vocabulary matches the words users actually use and search for. (GC2, GCE30)
- [ ] The page answers one need; no second audience or second task is bolted on. (GC9)
- [ ] No duplicate page answers the same question. (GCE4)
- [ ] Named owner and review date exist as metadata. (GC14, GCE3)
- [ ] Specialist terms are defined at first use on this page. (GCE23)

## Medium

- [ ] First three words of every heading and link carry the distinguishing meaning; no "Overview"/"About"/"Information" headings. (GCE11)
- [ ] Headings are semantic, sequential, one `h1`; subheadings at least every 300 words on long pages. (GCE19–GCE20)
- [ ] Paragraphs ≤ 5 rendered lines, one idea each. (GCE7)
- [ ] Bullets: ≤ 2 sentences per item, parallel grammar, lead-in line, ≤ 8 items. (GCE17–GCE18)
- [ ] Page ≤ 800 words, or the length is justified in the page record. (GCE21)
- [ ] No metaphor or figurative language in instructional content. (GCE25)
- [ ] No formal filler; no "simply"/"just"/"easy"/"obviously". (GCE26–GCE27)
- [ ] Link text describes the destination out of context; no "here"/"read more"/bare URLs. (GCE31–GCE32)
- [ ] Reader addressed as "you"; organisation named when it acts. (GCE29)
- [ ] Acronyms expanded at first use, and avoided where used fewer than 3 times. (GCE24)

## Low

- [ ] Numerals used for scannable numbers; thousands separated; `%` for percentages. (GCE35)
- [ ] Dates spelled out with month names, no ordinals, ranges use "to". (GCE36)
- [ ] Latin abbreviations replaced with plain equivalents. (GCE28)
- [ ] No bold/italic/caps/underline used for emphasis in body content. (GCE37)
- [ ] Meta description ≤ 160 characters and restates the answer. (GCE14)
- [ ] Volatile facts either carry a review date or link to the authoritative source rather than copying it. (GCE34)

## Process

- [ ] Need statement was derived from evidence (search terms, support volume, research), not from internal preference. (GC12)
- [ ] The estate was checked for an existing answer before this page was created. (GCE4)
- [ ] Post-launch review is scheduled within 1 month, against real search and drop-off data. (GC16)
- [ ] Retirement candidates identified in this review are redirected, not deleted or orphaned. (GC15, GCE40)
- [ ] Repeated support questions in this content area have been treated as content bugs and closed by fixing the page.
