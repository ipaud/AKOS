# Prompt Fragments — TDD Pack

```text
Apply TDD discipline (AKOS L2) for logic-bearing code: write a failing
test first (Red), verify it fails for the right reason; write the
minimum implementation to pass (Green), no speculative extras; refactor
only with the test suite green throughout (Refactor), never mixing new
behavior into a refactor step; assert on observable behavior, not
implementation internals; use triangulation (a second test) before
generalizing past a hardcoded-looking first implementation.
```
