# Pack: Test-Driven Development

**Domain:** Testing · **Authority:** Level 2 (Kent Beck / XP practice) · **Version:** 1.0.0

Operationalizes the Red-Green-Refactor cycle: writing a failing test before implementation, the minimum code to pass it, then refactoring with the safety net in place.

Independent distillation; not affiliated with or endorsed by Kent Beck. See [references.md](references.md).

## When to load
New feature/bugfix implementation where TDD discipline applies.
