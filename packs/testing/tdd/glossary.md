# Glossary — TDD Pack

- **Red-Green-Refactor** — the TDD cycle: failing test, minimal pass, safe restructure.
- **Triangulation** — using a second test case to force a genuine (non-hardcoded) implementation.
- **Spike** — exploratory throwaway code used to learn a design before writing it test-first "for real."
- **Two hats** — the discipline of never mixing behavior change and refactoring in one step (shared with [Fowler refactoring](../../architecture/martin-fowler-refactoring/glossary.md)).
