# Review Checklist — TDD Pack

## High
- [ ] New logic-bearing code has tests reflecting Red-Green-Refactor (or equivalent evidence). (TD-E1)
- [ ] Implementation is minimal to the test's requirement, no speculative extras. (TD-E2)

## Medium
- [ ] Refactor steps don't introduce new failing tests. (TD-E3)
- [ ] Tests assert behavior, not implementation internals. (TD-E4)

## Low
- [ ] Commit history reflects distinguishable test/implementation steps where practical. (TD-E5)
