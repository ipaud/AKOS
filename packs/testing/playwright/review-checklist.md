# Review Checklist — Playwright Pack

## High
- [ ] No fixed sleep/waitForTimeout in test code. (PL1)
- [ ] Role/label/text-based selectors used by default. (PL2)
- [ ] Tests isolated, no shared mutable state across tests. (PL3)

## Medium
- [ ] Trace/video capture enabled on CI failure. (PL4)
- [ ] E2E coverage scoped to critical journeys. (PL5)
- [ ] Test data seeded per-test via API/fixtures. (PL6)
