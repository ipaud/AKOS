# Glossary — Playwright Pack

- **Auto-waiting** — Playwright's automatic waiting for element actionability before interacting.
- **Locator** — Playwright's resilient, lazily-evaluated element reference (`getByRole`, etc.).
- **Test isolation** — ensuring each test runs independently with no shared state dependency.
- **Trace** — Playwright's recorded execution timeline for debugging failures.
- **Flaky test** — a test that intermittently fails without code changes.
