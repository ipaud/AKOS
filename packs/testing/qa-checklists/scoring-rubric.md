# Scoring Rubric — QA Checklists Pack

| Finding | Deduction |
|---------|-----------|
| Empty/error state untested and found broken | −15 (HIGH) |
| No boundary-value testing on new form/list features | −10 (HIGH) |
| No regression check before release | −10 (HIGH) |
| No degraded-network testing on primary flow | −6 (MEDIUM) |
| Browser matrix not based on real usage data | −4 (MEDIUM) |
| Unstructured/unreproducible exploratory findings | −2 (LOW) |

Anchors: 90 systematic full-checklist coverage · 75 solid, a category skipped · 60 happy-path-only QA · <50 no structured QA at all.
