# Review Checklist — QA Checklists Pack

## High
- [ ] Four states (empty/loading/error/success) verified on new async surfaces. (QA-E1)
- [ ] Boundary values tested (zero/one/max items, long/special-char input). (QA-E2)

## Medium
- [ ] Degraded network conditions tested on the primary shipped flow. (QA-E3)
- [ ] Browser/device matrix derived from real analytics. (QA-E4)
- [ ] Regression check performed for previously-fixed critical/high bugs. (QA-E6)

## Low
- [ ] Exploratory sessions have a charter and reproducible findings log. (QA-E5)
