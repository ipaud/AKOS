# Glossary — QA Checklists Pack

- **Four states** — empty, loading, error, success; the mandatory sweep for async surfaces.
- **Boundary value** — an edge-of-range input (zero, one, max, max+1) likely to expose bugs.
- **Exploratory testing** — structured, time-boxed, charter-driven improvisational testing.
- **Regression check** — verifying a previously-fixed bug hasn't returned.
- **Test matrix** — the set of browser/device combinations tested, ideally usage-weighted.
